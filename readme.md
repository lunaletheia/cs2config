### This is my personal autoexec for CS2, built off [ArminCs autoexec](https://github.com/ArmynC/ArminC-AutoExec)  
All settings are briefly commented, describing their use for easy adjustment   
Quality of life and debug scripts with audio feedback  
Keybinds are set using scancodes to be independent of keyboard layout (comments reference the german iso layout)  
Crosshairs saved in a folder with the ability to cycle through them
